## 실행 결과

OpenAI `gpt-6.1-sol`을 직접 호출하여 기존 백엔드 JSON 진단 API와 `shadow` 지식 그래프 경로를 검증했습니다. **합성 사례 5개 모두 기존 진단 검사에 통과했고, 실제 모델 호출은 총 7회였습니다. 그래프 5개도 모두 저장·SHACL 검증에 통과했습니다.**

## 로컬 실행 설정

원래 저장소의 `.env`에 제공한 LLM 설정과 `AGENT_KG_MODE=shadow`를 설정합니다. `.env`는 Git에서 제외되며 로컬 파일 권한은 0600입니다. 기본 코드 설정은 계속 `off`이고, 이 로컬 설정에서만 병행 검증을 활성화합니다.

macOS/Linux에서 저장소 루트로 이동한 뒤 실행합니다.

```bash
.venv/bin/python -m ai_error_check_agent.api --dev
```

`--dev`는 `127.0.0.1:8001`의 로컬 개발 실행입니다. 백엔드 입력을 `POST /diagnose`에 전달하면 실제 LLM을 호출하며, 진단 후 `.runtime/knowledge`에 그래프를 저장합니다. 기존 백엔드 입력·Agent 출력 규격은 유지됩니다.

같은 합성 사례를 다시 평가하려면 새 결과 디렉터리를 지정합니다. **재실행 시에도 실제 모델 사용량이 발생합니다.**

```bash
.venv/bin/python evaluation/run_backend_envelope.py --env-file .env --runtime direct --knowledge-mode shadow --output-dir results/backend-shadow-new
```

평가 결과는 `results/backend-llm-shadow-20261003`에 보관합니다. `summary.json`은 기존 시나리오 검사, `knowledge-metrics.json`은 토큰·그래프·구조적 CQ의 관찰값, 사례별 JSON은 공개 API 응답, `knowledge/`는 단계별 분석 레코드·RDF·SHACL 보고서입니다. 결과 디렉터리도 Git에서 제외됩니다.

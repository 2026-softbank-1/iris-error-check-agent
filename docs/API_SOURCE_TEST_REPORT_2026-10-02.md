## 자동 검증 범위

- 로그 단계에 소스 내용이 포함되지 않는지, 선택하지 않은 파일 내용이 다음 호출과 결과에서 제외되는지
- 파일 경로·줄 번호·로그 EV/코드 SC/원인 H 참조의 연결, 존재하지 않는 코드 위치 거절
- 소스 누락·범위 초과·코드 입력 예산 초과, 일부 파일만 읽은 경우의 한계 표시
- 비밀값·여러 줄 개인키 마스킹과 실제 줄 번호 유지, 소스 내 지시를 자료로 취급
- 코드 단계의 잘못된 응답·모델 오류·시간 초과에서 유효한 로그 진단 유지
- 시간 초과 시 어댑터 닫기, 공급자 완료 여부 미확인 표시, 모르는 토큰·호출 수를 0으로 만들지 않음
- 상대 경로·파일 수·크기·UTF-8·중복 경로·비밀 파일 입력 제한
- API 인증, JSON 중복 키·NaN·잘못된 입력의 안전한 오류 메시지, Content-Type·본문 크기 제한
- CORS 허용 목록, 동시 요청 제한과 처리 후 슬롯 반환, OpenAPI 참조 유효성
- 기존 CLI·전처리·진단 상태·상세 해결안·실행기 회귀 검사

실제 두 코드 진단의 설명과 수정안도 검토했습니다. TypeScript 결과는 타입 단언으로 오류를 숨기지 않고 실제 숫자 변환과 포트 범위 검사를 제시했습니다. Python 결과는 확인한 코드의 키 이름을 수정하면서 올바른 환경변수의 실제 전달 여부는 별도 검증 사항으로 남겼습니다. 생성 코드는 실행하거나 저장소에 적용하지 않았습니다.
